# 공개 노트북 소스 (읽기 전용 참고 자료)

2026-11-26에 Kaggle CLI(`kernels pull`)로 받은 `santa-2026` 대회 공개 노트북의 소스다.

**규칙 (사용자 결정, 2026-11-26): 코드와 설명만 참고한다.**

- 여기 있는 코드는 실행하지 않는다. 기법은 우리 엔진에 다시 구현한다.
- 일부 노트북 소스에는 다른 참가자의 결과 프로그램이 박혀 있다. 퍼즐 id가 수백 개 이상 나오는 것으로 확인한 것: `wangjakie_...`(1,000개), `lightningv08_...`(1,000개), `atakanaldemir_...`(363개), `avazaku_elf-calc-live-range-compactor`(154개). `_text/`의 추출본도 같다. 다른 노트북에도 id 없이 박혀 있을 수 있다.
- **그 프로그램들을 뽑아내거나 `results/`, `best/`에 넣지 않는다.** 출발점으로도 쓰지 않는다.
- 결과 프로그램 말고는 내용이 없던 두 폴더는 지웠다: `tkm2261_sorry-for-my-leakage-...`(스스로 "잠깐 공개됐던 노출에서 나온 프로그램"이라고 적은 258개 묶음), `bikrambasnet1_santa-2026-arithmetic-graph-rewrites`(프로그램 묶음과 짧은 글). 두 노트북에 대해 읽은 내용은 `catalog_2.md`에 있다.

정리: `catalog_1.md`(선두 엔진), `catalog_2.md`(재작성·레지스터·CP-SAT·GPU), `catalog_3.md`(분석·병합).
